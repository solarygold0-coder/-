# تشغيل النسخة الموقعة محلياً

الحزمة تحتوي ملف `SaudiPatientDesk.exe` وشهادة التوقيع العامة `SaudiPatientDesk.cer`.

على كل جهاز Windows جديد:

1. شغّل PowerShell كمسؤول.
2. نفّذ `03-install-certificate.ps1` من داخل مجلد الحزمة.
3. شغّل `SaudiPatientDesk.exe`.

هذه شهادة ذاتية مخصصة لأجهزة العيادة. لا تمنح سمعة SmartScreen عامة مثل شهادة تجارية، لكنها تتيح التحقق من سلامة الملف بعد تثبيت الشهادة على الجهاز.
