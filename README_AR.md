# نظام سجلات المرضى — الإصدار 7.1.1

تطبيق Windows عربي واحد لإدارة المراجعين والمواعيد والأطباء والأخصائيين والعيادات والطباعة والبحث والإعدادات والنسخ الاحتياطي. يبدأ مباشرة بلوحة التحكم دون شاشة دخول.

## مسار البيانات الثابت
`%LocalAppData%\SaudiPatientDesk\Clinic2026\clinic-records.sqlite3`

هذا المسار مستقل عن ملفات البرنامج ورقم الإصدار، لذلك تبقى بيانات المرضى عند التحديث. لا يفتح البرنامج قاعدة Generation6 التي كانت تسبب خطأ SQLite.

## التثبيت المعتمد

الإصدار 7.1.1 يستخدم حزمة MSIX بهوية ثابتة. يثبت ويندوز ملفات كل تحديث في مسار إصدار منفصل داخل `WindowsApps`، ويجعل اختصاراً واحداً يشغّل الإصدار النشط. استخدم الملف `05-install-msix.ps1` الموجود مع حزمة MSIX للتثبيت أو التحديث؛ فهو يثبت الشهادة ويستبدل اختصار سطح المكتب القديم دون حذف قاعدة البيانات.

يجب استخدام شهادة PFX دائمة واحدة لكل الإصدارات من خلال أسرار GitHub:

- `WINDOWS_SIGNING_PFX_BASE64`
- `WINDOWS_SIGNING_PFX_PASSWORD`

إذا لم تتوفر الأسرار ينتج البناء حزمة اختبار بشهادة مؤقتة ويذكر ذلك في `package-info.txt`.

## خصائص أساسية

- واجهة عربية كاملة من اليمين إلى اليسار، مع استثناء حقول الأرقام فقط.
- التواريخ ميلادية حصراً.
- تعديل بيانات المراجع والموعد وإلغاء المواعيد القادمة عند حذف المراجع.
- اختيار جميع ساعات اليوم و60 دقيقة، مع التحقق من الدوام والاستراحة وأيام الإغلاق.
- زر إعدادات، طباعة بطاقة المراجع، وطباعة الموعد.
- حفظ البيانات في `%LocalAppData%` مع نسخ احتياطية تلقائية ويدوية.
- أيقونة البرنامج مضمنة في الملف التنفيذي.

## البناء
من ويندوز مع .NET 10:
```
dotnet publish src/SaudiPatientDesk/SaudiPatientDesk.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

عند الرفع إلى GitHub يبني Actions حزمة MSIX الرسمية فقط. بقي بناء EXE المحمول يدوياً للطوارئ، حتى لا تظهر عدة حزم متشابهة وتُشغّل النسخة الخطأ.
