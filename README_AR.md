# نظام إدارة سجلات المراجعين — الإصدار 1.1

تطبيق مكتبي عربي محلي لإدارة ملفات المراجعين والمواعيد والمهام على ويندوز. الواجهة بسيطة وتعمل بكامل الشاشة مع أزرار ويندوز القياسية للتصغير والتكبير والإغلاق.

## الوظائف المنفذة

- رقم ملف متسلسل يبدأ من 1 ولا يعاد استخدامه بعد أرشفة مراجع.
- حد إداري واضح يبلغ 10,000 مراجع مع فهارس للملف والهوية والاسم والجوال.
- هوية وطنية أو إقامة من 10 أرقام، مع قبول الأرقام العربية `٠١٢٣٤٥٦٧٨٩` والإنجليزية وتحويلها تلقائيًا، وفحص رقم التحقق السعودي.
- كشف التكرار بالهوية، وتطبيع الهمزات والمسافات والتشكيل في الأسماء قبل مقارنة الاسم مع الميلاد أو الجوال.
- بحث بالملف أو الهوية/الإقامة أو الاسم أو الجوال، وفرز متعدد.
- إنشاء الموعد بإدخال رقم الملف ثم تعبئة اسم المراجع وهويته وجواله تلقائيًا.
- منع حجز الجمعة والسبت، ومنع التداخل، ومنع الوقت الماضي وخارج الدوام، مع قائمة ميلادية لإجازات المنشأة.
- إدخال الميلادي والوقت بقوائم تمرير فقط، مع رقم الشهر واسمه.
- طباعة إشعار الموعد من معاينة الطباعة.
- المهام والتنبيهات مرتبطة دائمًا بملف مراجع؛ الضغط على الاسم أو عنوان المهمة/الموعد يفتح الملف.
- جرد سنوي يعتمد على مواعيد الحضور الفعلية حتى تاريخ الفحص ويعاد حسابه بعد تعديل أو حذف الموعد.
- أرشفة المراجع تلغي مواعيده المستقبلية وتغلق مهامه المفتوحة مع إبقاء رقم الملف ثابتًا.
- حسابات موظفين مستقلة بصلاحيات مدير وموظف وقراءة فقط، مع تسجيل اسم منفذ العملية وقفل تلقائي بعد 15 دقيقة.
- إغلاق النافذة يبقي البرنامج في منطقة الإشعارات لاستمرار التنبيهات، مع منع تكرارها بعد إعادة التشغيل.
- حذف المواعيد والمهام ينقلها إلى محذوفات قابلة للاستعادة.
- نسخ احتياطي دوري قابل للضبط، وفحص SHA-256 للسلامة، واحتفاظ بآخر 30 نسخة، مع إظهار حالة الفشل.
- طباعة ملخص إداري للمراجع يشمل بياناته وأحدث مواعيده ومهامه.
- قاعدة بيانات مشفرة، وسجل تدقيق، وحفظ فوري، وتصدير CSV محمي من صيغ Excel التنفيذية.
- تصدير CSV بتحذير خصوصية واضح، ونسخ احتياطي واستعادة.

## التوافق

يستهدف التطبيق `.NET Framework 4.7.2` ويعمل على Windows 7 SP1 وWindows 8 وWindows 10 وWindows 11. يلزم تثبيت .NET Framework 4.7.2 أو 4.8. ويندوز 7 منتهي الدعم الأمني من مايكروسوفت؛ تشغيل بيانات مرضى عليه غير مستحسن إلا على جهاز معزول ومؤمّن.

## البناء

على جهاز Windows مثبت عليه Visual Studio 2022 Build Tools مع حزمة تطوير سطح المكتب لـ .NET Framework:

```powershell
powershell -ExecutionPolicy Bypass -File .\build-windows.ps1
```

الناتج: `release\App\سجلات_المرضى.exe`. يمكن بناء المثبت بواسطة Inno Setup 6 من ملف `Installer.iss`.

## ملاحظات التشغيل

- عند أول تشغيل ينشأ حساب المدير باسم المستخدم `admin`، ثم يمكن للمدير إضافة حسابات الموظفين.
- الضغط على زر الإغلاق يخفي النافذة ويبقي التنبيهات عاملة بجانب ساعة ويندوز؛ استخدم قائمة الأيقونة واختر «إنهاء البرنامج» للإغلاق الكامل.
- يبدأ البرنامج تلقائيًا مع دخول ويندوز لكنه يطلب بيانات المستخدم ولا يخزن كلمة المرور.

## ملاحظة نظامية

التصميم يراعي مبادئ تقليل الوصول، التشفير، التحقق، السجل التدقيقي، النسخ الاحتياطي، وعدم الإتلاف التلقائي. لكنه ليس شهادة امتثال قانونية أو اعتمادًا من وزارة الصحة؛ على المنشأة اعتماد سياسة الاحتفاظ والإتلاف والصلاحيات وفق نوعها وتعليمات الجهة المنظمة والعقود النافذة.
