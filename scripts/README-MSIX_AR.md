# تثبيت نظام سجلات المرضى — MSIX

هذه الحزمة هي طريقة التثبيت المعتمدة ابتداءً من الإصدار 7.1.0. يفصل ويندوز ملفات كل إصدار تلقائياً ويشغّل إصداراً واحداً فقط من خلال هوية التطبيق الثابتة.

## التثبيت أو التحديث

1. فك ضغط ملف الإصدار بالكامل في مجلد جديد.
2. انقر بزر الفأرة الأيمن على `05-install-msix.ps1`.
3. اختر **تشغيل باستخدام PowerShell**.
4. إذا منع ويندوز تشغيل السكربت، افتح PowerShell داخل المجلد ونفّذ:

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\05-install-msix.ps1
```

ينفذ الملف ما يلي:

- يطلب موافقة صريحة قبل تثبيت شهادة الناشر الذاتية في مخزن الجذر للمستخدم الحالي، ثم يضيفها إلى مخزن الأشخاص الموثوق بهم.
- يثبت الحزمة أو يحدّث النسخة المسجلة مسبقاً.
- يغلق النسخة القديمة أثناء التحديث.
- يستبدل اختصار سطح المكتب باختصار ثابت مرتبط بهوية التطبيق، وليس بمجلد إصدار قديم.

## البيانات

التحديث لا يحذف بيانات المرضى. تبقى قاعدة البيانات والنسخ الاحتياطية والمرفقات في:

```text
%LocalAppData%\SaudiPatientDesk\Clinic2026
```

لا تنقل قاعدة البيانات إلى مجلد MSIX ولا إلى مجلد البرنامج؛ لأن ملفات البرنامج تستبدل عند التحديث.

## الشهادة الدائمة

يجب توقيع جميع التحديثات بالشهادة الدائمة نفسها. إذا ذكرت `package-info.txt` أن وضع التوقيع هو `temporary-development` فهذه حزمة اختبار، ويجب تثبيت الشهادة المرفقة قبل تثبيت الحزمة.
