# نظام إدارة سجلات المرضى

تطبيق مكتبي عربي محلي لإدارة ملفات المراجعين والمواعيد والمهام على ويندوز. الواجهة بسيطة وتعمل بكامل الشاشة مع أزرار ويندوز القياسية للتصغير والتكبير والإغلاق.

## الوظائف المنفذة

- رقم ملف متسلسل يبدأ من 1 ولا يعاد استخدامه بعد أرشفة مراجع.
- قاعدة بيانات مفهرسة مناسبة لأكثر من 100,000 مراجع.
- هوية وطنية أو إقامة من 10 أرقام، مع قبول الأرقام العربية `٠١٢٣٤٥٦٧٨٩` والإنجليزية وتحويلها تلقائيًا، وفحص رقم التحقق السعودي.
- كشف التكرار بالهوية، والتنبيه عند تطابق الاسم مع الميلاد أو الجوال.
- بحث بالملف أو الهوية/الإقامة أو الاسم أو الجوال، وفرز متعدد.
- إنشاء الموعد بإدخال رقم الملف ثم تعبئة اسم المراجع وهويته وجواله تلقائيًا.
- منع حجز الجمعة والسبت، ومنع أي تداخل زمني بين المواعيد.
- إدخال الميلادي والوقت بقوائم تمرير فقط، مع رقم الشهر واسمه.
- طباعة إشعار الموعد من معاينة الطباعة.
- المهام والتنبيهات مرتبطة دائمًا بملف مراجع؛ الضغط على الاسم أو عنوان المهمة/الموعد يفتح الملف.
- جرد سنوي للملفات التي لم تسجل حضورًا منذ عشر سنوات، ثم أرشفة يدوية موثقة بعد المراجعة.
- قاعدة بيانات مشفرة بكلمة مرور، وسجل تدقيق، وحفظ فوري، ونسخة احتياطية يومية مشفرة عند الإغلاق.
- تصدير CSV بتحذير خصوصية واضح، ونسخ احتياطي واستعادة.

## التوافق

يستهدف التطبيق `.NET Framework 4.7.2` ويعمل على Windows 7 SP1 وWindows 8 وWindows 10 وWindows 11. يلزم تثبيت .NET Framework 4.7.2 أو 4.8. ويندوز 7 منتهي الدعم الأمني من مايكروسوفت؛ تشغيل بيانات مرضى عليه غير مستحسن إلا على جهاز معزول ومؤمّن.

## البناء

على جهاز Windows مثبت عليه Visual Studio 2022 Build Tools مع حزمة تطوير سطح المكتب لـ .NET Framework:

```powershell
powershell -ExecutionPolicy Bypass -File .\build-windows.ps1
```

الناتج: `release\سجلات_المرضى\سجلات_المرضى.exe`. يمكن بناء المثبت بواسطة Inno Setup 6 من ملف `Installer.iss`.

## ملاحظة نظامية

التصميم يراعي مبادئ تقليل الوصول، التشفير، التحقق، السجل التدقيقي، النسخ الاحتياطي، وعدم الإتلاف التلقائي. لكنه ليس شهادة امتثال قانونية أو اعتمادًا من وزارة الصحة؛ على المنشأة اعتماد سياسة الاحتفاظ والإتلاف والصلاحيات وفق نوعها وتعليمات الجهة المنظمة والعقود النافذة.
