# نظام سجلات المرضى — الإصدار 7.0.10

تطبيق Windows عربي واحد لإدارة المراجعين والمواعيد والأطباء والأخصائيين والعيادات والطباعة والبحث والإعدادات والنسخ الاحتياطي. يبدأ مباشرة بلوحة التحكم دون شاشة دخول.

## مسار البيانات الجديد
`%LocalAppData%\SaudiPatientDesk\Clinic2026\clinic-records.sqlite3`

لا يفتح قاعدة Generation6 التي كانت تسبب خطأ SQLite.

## خصائص أساسية

- واجهة عربية كاملة من اليمين إلى اليسار، مع استثناء حقول الأرقام فقط.
- التواريخ ميلادية حصراً.
- تعديل بيانات المراجع والموعد وإلغاء المواعيد القادمة عند حذف المراجع.
- اختيار جميع ساعات اليوم و60 دقيقة، مع التحقق من الدوام والاستراحة وأيام الإغلاق.
- زر إعدادات، طباعة بطاقة المراجع، وطباعة الموعد.
- حفظ البيانات في `%LocalAppData%` مع نسخ احتياطية تلقائية ويدوية.
- أيقونة البرنامج مضمنة في الملف التنفيذي.

## البناء
من ويندوز مع .NET 10:
```
dotnet publish src/SaudiPatientDesk/SaudiPatientDesk.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

أو ارفع المجلد إلى GitHub وسيبني Actions ملف exe.
