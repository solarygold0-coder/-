# نظام إدارة سجلات المراجعين — الإصدار 6.0.0

تطبيق مكتبي عربي حديث لإدارة سجلات المراجعين والمواعيد والمهام. هذا الإصدار إعادة بناء مستقلة، وليس ترقيعًا للإصدارات السابقة.

## البنية التقنية

- الواجهة: WPF على .NET 10 مع WPF-UI 4.3 وتصميم Fluent ودعم كامل لاتجاه RTL.
- قاعدة البيانات: SQLite مشفرة بواسطة SQLCipher، محلية ولا تحتاج خادمًا.
- التشغيل: تطبيق Win32 غير محزم، مع ملف EXE مستقل ومعالج تثبيت WiX تفاعلي.
- الأنظمة: Windows 10 وWindows 11 بنواة x64.
- السعة الإدارية: 10,000 مراجع.

لا يحتوي المصدر على WinForms أو LiteDB أو MSIX أو UWP. ولا يوجد حساب `admin` أو كلمة مرور افتراضية.

## سلوك التشغيل الأول

- يفتح التطبيق مباشرة دون شاشة دخول.
- تُنشأ قاعدة بيانات جديدة داخل `%LOCALAPPDATA%\SaudiPatientRecordsV6`.
- لا يقرأ التطبيق قواعد أو إعدادات أو حسابات الإصدارات السابقة تلقائيًا.
- يمكن للمالك المحلي إنشاء حسابات بأسماء شخصية ثم تفعيل شاشة الدخول من الإعدادات.
- لا يمكن تفعيل شاشة الدخول قبل إنشاء مدير مسمى وفعال.

## الوظائف

- أرقام ملفات تسلسلية تبدأ من 1 ولا يعاد استخدامها بعد الأرشفة.
- تحقق سعودي للهوية الوطنية والإقامة مع قبول الأرقام العربية وتحويلها داخليًا.
- كشف التكرار بالهوية وبمزيج الاسم وتاريخ الميلاد والجوال.
- بحث برقم الملف أو الهوية/الإقامة أو الاسم أو الجوال أو المدينة، مع فرز قبل تطبيق حد النتائج.
- مواعيد ميلادية فقط، وإدخال التاريخ والوقت بقوائم تمرير.
- منع الجمعة والسبت وأيام الإغلاق والأوقات خارج الدوام وتعارض المواعيد.
- تعبئة بيانات المراجع تلقائيًا من رقم الملف، مع فرض الربط الصحيح داخل طبقة البيانات.
- طباعة بطاقة موعد.
- مهام وتنبيهات مرتبطة بالمراجع؛ الضغط على الاسم أو الموعد أو المهمة يفتح ملفه.
- جرد سنوي للملفات التي لم تسجل مراجعة منذ عشر سنوات أو أكثر.
- أرشفة دون تغيير أرقام بقية الملفات، وسجل تدقيق، ومرفقات مشفرة داخل SQLite.
- نسخ احتياطي تلقائي ويدوي مع فحص SHA-256 وفحص سلامة SQLite.

## البناء

المتطلبات: Windows 10/11 x64 و.NET 10 SDK.

```powershell
.\publish-standalone.ps1
```

ينتج ملفًا واحدًا: `release-standalone\Saudi-Patient-Records.exe`.

ولإنشاء معالج تثبيت تفاعلي من نوع «التالي، التالي»:

```powershell
.\build-installer.ps1
```

النتائج:

- `release-installer\Saudi-Patient-Records-Setup.exe`
- `release-installer\Saudi-Patient-Records-Standalone.exe`
- `release-installer\BUILD-INFO.txt`

ملفات EXE الناتجة غير موقعة رقميًا. وجود معلومات الناشر والبصمة SHA-256 لا يعادل شهادة توقيع، وقد يعرض Windows SmartScreen تحذير سمعة للملفات الجديدة غير الموقعة.

## الخصوصية

هذا برنامج إداري محلي، وليس نظام تشخيص أو وصف علاج. على الجهة المستخدمة تطبيق سياسات الصلاحيات والنسخ الاحتياطي والاحتفاظ بالسجلات والخصوصية المعتمدة لديها.
